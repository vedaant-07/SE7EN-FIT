# Phase 5 test matrix

| Area | Required result |
|---|---|
| AI Coach retry | Same request ID does not create duplicate responses |
| AI quota | Concurrent requests cannot exceed the plan quota |
| AI safety | Urgent symptoms return stop-and-seek-care guidance |
| Food upload | Unsupported type or file over 8 MB is rejected |
| Food confirmation | All corrected items save together or none save |
| Workout generation | New plan archives the previous active plan |
| Workout completion | Repeated completion does not duplicate activity |
| Nutrition | Targets show estimated versus profile-complete confidence |
| Step summary | Daily health snapshots are not summed together |
| Offline UI | Cached summaries are clearly labelled and retry remains available |
